# Apex University Landing Page 🎓

A modern, responsive and interactive landing page concept for **Apex University, Jaipur**, built using pure **HTML, CSS and JavaScript**.

The project focuses on a clean university-style interface with modern animations, responsive layouts and smooth user interactions.

---

## 🚀 Features

* Modern university landing page design
* Fully responsive for desktop, tablet and mobile
* Sticky navigation bar
* Mobile hamburger menu
* Smooth scrolling navigation
* Active navigation section highlighting
* Animated statistics counters
* Scroll reveal animations
* Interactive program cards
* Campus and facilities section
* Call-to-action section
* Back-to-top button
* Mouse-based hero card interaction
* SEO-friendly HTML structure
* Accessible labels and semantic HTML
* No external image dependency

## ▶️ How to Run

### Method 1 — Directly in Browser

1. Download or clone the project.
2. Open the project folder.
3. Double-click `index.html`.
4. The landing page will open in your browser.

### Method 2 — VS Code + Live Server

1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Open `index.html`.
4. Right-click inside the file.
5. Select **Open with Live Server**.

The project will then open in your browser.

## 🔧 Customization

You can easily customize the website by editing the following:

### Change Colors

Open `style.css` and modify the variables:

```css
:root {

    --primary: #8b1e2d;
    --primary-dark: #651421;
    --primary-light: #b53b4b;

    --gold: #d9a441;

    --dark: #111216;

}
```

### Change Hero Text

Open `index.html` and find:

```html
<h1>
    Shape Your
    <span>Future</span>
    at Apex
</h1>
```

You can replace this text with your own headline.

### Add More Programs

Copy an existing program card inside:

```html
<div class="program-grid">
```

and modify the title, description and link.
